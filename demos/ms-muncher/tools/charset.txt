# Ms. Muncher's glyph sheet -- multicolor text mode, 4 pairs a row.
#   .  = background ($D021, black)
#   1  = $D022, the per-maze wall highlight
#   2  = $D023, pink (the house door and fruit outlines)
#   3  = the cell's own colour nybble
#
# Codes 96-111 are the sixteen wall shapes, indexed by which neighbours are
# also wall: bit0 up, bit1 left, bit2 down, bit3 right.  The maze stores no
# wall art at all -- maze.s picks the shape from the four neighbours, which
# is why four different layouts need one set of glyphs.
#
#   c64 charset encode demos/ms-muncher/tools/charset.txt --first-code 96 \
#       -o demos/ms-muncher/chars.inc
