# La Galaxia -- the settled-enemy character blocks, drawn as whole 16x16
# pictures.  tools/genblocks.py splits each one into the four 8x8 quadrants
# the screen matrix needs and writes them out in `c64 charset encode` form,
# so the art is authored as a picture and encoded by the standard tool.
#
# Two animation frames per type.  Emitted order is screen-code order:
# drone f0, drone f1, sentinel f0, sentinel f1, flagship f0, flagship f1,
# four quadrants each (TL, TR, BL, BR), starting at code 64.
#
