# La Galaxia -- every sprite shape, as readable art.
# `c64 sprite encode tools/sprites.txt --background .` reads this file as it
# stands: `name:hires` / `name:multicolor` headers, `#` comments, and a
# background you can see.  Legend (the pair value IS the digit):
#
#     .  background, pair 00      #  the sprite's own colour, pair 10
#     1  $D025 (red), pair 01     3  $D026 (blue), pair 11
#
# The 16x16 arcade shapes are centred in the C64's 24x21 box, so a sprite
# coordinate and the art coordinate never drift apart: hires art occupies
# columns 4-19, multicolour art columns 2-9 (of 12 double-wide pixels).
#
# File order is block order, and it is the manifest sprites.s indexes off:
# SPRBLK + 0 is the first block below.  Hires first (5 shapes), then
# multicolour (16).  Original art throughout.
