# chars.txt — Snake's custom glyphs, 8x8 hires ASCII art.
#
# Regenerate the assembler source with:
#   .venv/bin/c64 charset encode chars.txt --hires --first-code 112 -o chars.inc
#
# Block order IS screen-code order, starting at 112 — ROM graphics characters
# the game never draws.  Staying below 128 keeps the whole reverse-video half
# of the character set (129-154 are reverse A-Z) available for text.
# The border is a double line: its two rails sit on rows 1-2 and 5-6 of the
# horizontal piece and columns 1-2 and 5-6 of the vertical one, which is what
# lets the four corners join them up without a step.  The body carries a scale
# dot pattern and the heads do not, so a solid blob with a 2x2 eye hole
# facing the way it travels reads as the head at 1x.
