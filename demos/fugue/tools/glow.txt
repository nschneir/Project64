# The note backlight, one 24x21 hires sprite.
#
# The lit band occupies sprite rows 7-13, centred on row 10. A sprite whose Y
# register is V shows its first row on raster V+1, so row 10 lands on raster
# V+11 -- which is what makes the tracking formula in SPEC.md section 8,
#
#     sprite Y = 74 + 4*p
#
# centre the glow on the note head at ladder position p (head top raster is
# 51 + 8*BANDTOP + 4*p with BANDTOP = 4, head centre 1.5 rasters below that).
#
# The band is 12 px wide in bits 6-17 with rounded ends. At age 0 the sprite
# sits at x = 102 and the head it backlights spans x 111-116, so the glow
# reaches 3 px past the head on each side: a halo, not a slab. It is drawn
# BEHIND the character data ($D01B bits 0-2 set), so only the cell's
# background pixels take the glow colour and the note head's own white pixels
# stay white.
#
# Rows 0-6 and 14-20 are deliberately empty: a taller glow would spill into
# the neighbouring diatonic position, which is only 4 px away.
